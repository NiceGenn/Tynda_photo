# Было → Стало · Генератор плашек

Веб-приложение, которое из фото **«Было.jpg»** делает готовую плашку **«Стало.jpg»**:
создаёт фон-подложку (по умолчанию `1000×675`), располагает исходное изображение
по центру, немного уменьшая его, добавляет рамку, скругление, тень.

Вся обработка выполняется **прямо в браузере** на `<canvas>` — файлы никуда не
загружаются, сервер не нужен.

## Вкладки

- **🖼 Плашки** — основной генератор (см. ниже)
- **🗜 Сжатие фото** — уменьшение веса тяжёлых снимков без заметной потери качества:
  - пресеты «Бережно / Оптимально / Максимум» и ручные настройки
  - умный выбор формата (JPEG остаётся JPEG, PNG → WebP)
  - **поворот и зеркало** — по одному фото или сразу всем
  - **целевой вес**: задаёте «до 500 КБ» — качество подбирается автоматически,
    при необходимости уменьшается и размер
  - **сравнение с оригиналом** — шторка 1:1 с перетаскиванием, видно артефакты
  - **HEIC/HEIF с айфонов** — декодируются через libheif 1.23 (WASM,
    грузится только при появлении такого файла); если браузер умеет сам
    (Safari) — используется он
  - **редактор**: кадрирование с пропорциями, выравнивание горизонта
    (пустые углы обрезаются автоматически), яркость/контраст/насыщенность,
    автоконтраст по гистограмме
  - **водяной знак** — текст или логотип, положение, размер, прозрачность
  - **повышение резкости** после уменьшения (нерезкое маскирование),
    с подсказкой, когда фото ужимается заметно
  - **профили площадок**: для сайта, ВК, Telegram, почты
  - вставка из буфера обмена (Ctrl+V)
  - показ «было → стало» по каждому файлу и общим итогом
  - если сжатый файл тяжелее оригинала — отдаётся оригинал
  - при перекодировании удаляются EXIF-данные, включая GPS-координаты съёмки

## Возможности

- Загрузка перетаскиванием или кликом, **можно несколько фото сразу**
- **Два режима**:
  - **Плашка** — каждое фото превращается в свою плашку (пакетно)
  - **Коллаж** — несколько фото собираются в один коллаж (9 макетов: 2×2, колонки,
    «большая + маленькие», «2 сверху + 3 снизу» и др.) с настройкой зазоров,
    их цвета, скругления и пропорций — и уже коллаж ложится на плашку
- **Пакетный экспорт**: все плашки одним архивом **ZIP** (без внешних библиотек)
- **Пресеты настроек** — сохраняются в браузере, применяются в один клик
- Размер плашки настраивается (пресеты `1000×675`, `1200×800`, `1080×1080`, Stories `9:16`, `1920×1080`)
- Четыре режима фона:
  - **Пресет** — бирюзово-синий градиент (как на образце), оттенок регулируется
  - **Адаптивный** — градиент подбирается под доминирующие цвета «Было»
  - **Размытие** — размытая увеличенная копия самого фото в качестве фона
  - **Цвет** — однотонная заливка
- **Библиотека декора фона** (26 стилей) с регулировкой плотности и цвета:
  - *Свет и блеск*: боке, блёстки ✨, звёздная пыль, лучи света, салют 🎆, круги на воде
  - *Природа*: пузырьки, снег ❄️, лепестки 🌸, сердечки ❤️, волны 〰️, листья 🍃
  - *Геометрия*: точечная сетка, линии сетки, диагональные полосы, треугольники, плюсики, соты
  - *Праздник и фактура*: конфетти 🎊, зерно (плёнка), виньетка
  - *Сочетания*: боке+блёстки, снег+блёстки, боке+виньетка, зерно+виньетка, звёзды+лучи
- **Текст поверх**: заголовок с выбором положения (9 позиций), стиля (плашка/тень/обводка),
  шрифта, цвета, размера
- Масштаб вставляемой картинки, скругление углов, тень, рамка (цвет, толщина)
- Экспорт в **JPG** или **PNG** с настройкой качества
- **PWA** — устанавливается как приложение и работает офлайн

## Как запустить

Просто откройте `index.html` в браузере — зависимостей нет.

Локальный сервер (не обязателен):

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Публикация на GitHub Pages

1. Settings → Pages
2. Source: `Deploy from a branch`
3. Branch: выбранная ветка, папка `/ (root)`
4. Приложение будет доступно по адресу `https://<user>.github.io/<repo>/`

## Структура

```
index.html          — разметка и панель настроек
styles.css          — оформление
app.js              — логика композиции на canvas (фон, декор, текст, экспорт, пресеты)
zip.js              — минимальный ZIP-упаковщик для пакетного экспорта
sw.js               — service worker (офлайн-кэш)
manifest.webmanifest, icon.svg — PWA
```

## Как это работает

1. Изображение читается через `FileReader`/`URL.createObjectURL` — остаётся в браузере.
2. Для адаптивного фона берётся уменьшенная копия и усредняется цвет по краям →
   строится диагональный HSL-градиент.
3. На плашку рисуется фон, затем по центру — исходник (с сохранением пропорций),
   со скруглением через `clip()`, рамкой и тенью.
4. `canvas.toDataURL()` отдаёт готовый файл на скачивание.
